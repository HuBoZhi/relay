使用指南

观察这个控制中心

  1. 选择频道

    左侧频道和图上的频道节点均可点击，右侧详情随之切换。

  2. 追踪智能体

    点击节点查看当前任务、工作状态与运行主机；可切换到「频道聚焦」。

  3. 阅读完整消息

    长消息默认折叠三行，可原地展开；点击正文进入完整阅读窗口。

  4. 控制信息密度

    支持频道筛选、消息搜索、发送者与日期筛选、缩放和拖动画布。

状态含义：「执行中」来自任务事件；「近期有消息」只表示频道有新消息，不代表正在执行；信息不足时显示「未知」，不会当作空闲。快捷键：斜杠键搜索频道，退出键关闭弹窗。
