使用指南

探索这个控制中心

  1. 选择频道

    左侧频道和图上的频道节点均可点击，消息与状态随之切换。

  2. 追踪智能体

    点击小圆点，或切换「频道聚焦」，查看每个智能体正在执行的任务。

  3. 阅读完整消息

    长消息可原地展开；点击正文或放大按钮，进入完整阅读窗口。

  4. 控制信息密度

    支持频道筛选、消息搜索、发送者与日期筛选、缩放和拖动画布。

所有名称、消息与指标均为演示数据。暂停仅冻结原型中的流转演示。快捷键：按斜杠键搜索频道，按退出键关闭弹窗。
