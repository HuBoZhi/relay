## 建议体验路径

1. 查看中央全局数据流转，点击左侧 “研究分析”、“质量审查” 等频道，观察详情联动。
2. 返回 “工程研发”，点击其长消息的“展开全文”，再点击正文或放大按钮。
3. 在阅读窗口中查看完整内容、复制全文、切换前后消息，使用 Esc 关闭。
4. 点击图中的 “开发乙” 节点，查看任务和主机；切换“频道聚焦”。
5. 使用频道工作状态筛选、消息搜索、发送者和日期筛选；“历史归档” 包含昨日归档消息。
6. 阅读时间线较早记录时，等待演示新消息，观察保留阅读位置和新消息提示。

快捷键：斜杠键搜索频道，退出键关闭阅读窗口。画布支持拖动、缩放、重置和全屏。

## 设计依据

- 视觉主张：石墨黑、细网格与青色流光；琥珀色只承担异常提示。
- 信息顺序：系统总览 → 频道 → 智能体/消息 → 单条完整内容。
- 交互主张：用沿线流动表达方向，用联动选择保持上下文，用独立阅读窗口承接长内容。
- 桌面三栏布局，窄屏改为上下排列。原型以桌面使用为主。
- 使用零构建依赖的 HTML、CSS、JavaScript，便于本地预览、修改与交付。

## 数据与边界

所有频道、智能体、主机、任务、消息、时间和指标均为演示数据。原型包括 8 个频道、24 个智能体，其中 5 个频道及 11 个智能体展示为正在工作。演示时钟从 2026-10-26 14:32:08 北京时间 开始；页面可见且未暂停时，每 12 秒生成一条演示消息。

中央“协作中枢” 表示逻辑工作空间；预设的拓扑粒子只演示视觉语法，不代表真实网络包或真实业务事件。吞吐趋势和汇总指标也为演示统计。消息记录对每个频道限制为约 45 条，刷新页面重置。

未接入真实 API、认证、持久化、历史分页、任务状态推导及断线重放。未实现 Markdown 富文本和附件阅读。正式产品的这些要求已列入需求文档。
