# Relay系统桌面体验检查（2026-11-06）

任务范围：启动、终端依赖、窗口与托盘、退出与资源清理、设置保存、菜单、聊天输入与页面切换。
用户原有任务、消息和未提交文件不作为验收数据修改；测试文件与缓存使用 D 盘独立目录。

## 已定位问题

| Before | After | Why |
| --- | --- | --- |
| 登录启动仍指向 PowerShell，手动启动记录携带 `--no-window` | 原生 GUI 为入口，登录才追加静默参数 | 消除终端依赖，点击图标就显示窗口 |
| 创建窗口前等待桥接启动 | 先显示窗口，再启动桥接和客户端 | 慢连接不再表现为图标无响应 |
| 消息增多时整页变高，输入框在窗口外 | 聊天固定为窗口高度，消息与输入区分别滚动 | 输入区必须保持可见 |
| 后台刷新让阅读位置跳到末尾、输入失焦 | 保持阅读位置、输入内容和光标选区；中文组合输入时延后重绘 | 不打断阅读和输入 |
| 连续点击发送可产生重复提交，切群丢失草稿 | 请求期间拒绝重复提交，各群分别保存草稿 | 防止误派活和内容丢失 |
| 设置页保存失败只记日志，且内存已被改动 | 保存成功后更新内存；系统启动项失败时回滚文件，向页面返回错误 | 不能虚报成功 |
| 连接器更改未计入重启提示 | 对比启动时快照，覆盖连接器、端口、桥接、数据目录 | 界面应反映实际生效时机 |
| 退出事件中不等待异步资源释放 | 退出前等待服务、桥接、设置写入和引擎释放；启动中的桥接可取消 | 关闭程序不能留下桥接和未完成写入 |
| 桌面菜单首次点击快照无变化 | 后续截图确认可打开；群聊与任务页统一菜单，支持方向键、Esc、焦点返回 | 设置和退出入口必须可靠 |
| 安装目录网页落后于已提交源码 | 修复结束后同步并核验 | 用户必须实际用到已修复版本 |

## 启动修复验证

- 原生 GUI 的 PE subsystem 为 2；直接启动后 shell 命令已结束，窗口继续运行，窗口清单没有可见控制台。
- 保留 `--system-launcher` 集成配置，客户端启动由原生程序在窗口出现后以隐藏子进程触发。
- 登录命令参数及客户端启动有回归测试；不在命令中保存凭据。
- `trail` 已有其他活动任务；本记录独立保留，避免改动他人的 trajectory。

## 设置验证

- 38 项桌面 Vitest 测试通过，覆盖磁盘保存失败不改内存/启动项、系统拒绝启动项后回滚文件、连接器与端口的重启提示。
- 设置更新串行执行；托盘菜单与设置页共用同一更新入口和同一原生登录启动参数。

## 退出验证

- 测试覆盖等待未完成设置写入、引擎最后释放、桥接失败后仍释放引擎、卡住时有界退出、退出期间取消启动，以及可执行文件缺失不产生未处理的 error 事件。
- 重复手动启动仅恢复原窗口；带 `--no-window` 的登录重入不把托盘窗口突然弹出来。启动尚未就绪时的手动打开请求延后兑现。

## 聊天验证

- 9 项 DOM 测试通过，包括刷新保留光标选区、中文输入法组合期间不发送、草稿持久化和重复提交防护。
- 使用真实 Chromium、80 条消息，在 1360×900、1080×700、1024×640 三个尺寸验证输入框完全在窗口内、整页不滚动、消息独立滚动、刷新不改变旧消息阅读位置。

## 设置页与菜单恢复体验

- 服务读取失败时仍可打开设置；刷新不丢弃未保存设置，派发表单重绘前保存编辑内容；同页 hash 导航生效。
- 菜单保持键盘焦点、方向键导航、Esc 关闭并返回触发按钮；任务页补齐同样的菜单与标题栏拖动区。
- 提供原生目录选择、打开数据/日志文件夹、待重启更改的直接重启按钮；开发者接口默认折叠。
- 数据目录拒绝相对路径和 C 盘路径，错误在保存前返回。

## 窗口记忆

- 关闭时保留正常窗口位置、大小、最大化和缩放；再次打开恢复。
- 对已拔掉的屏幕、超大/损坏窗口记录进行工作区约束，避免窗口或标题栏落在屏幕外。小工作区不再被固定 1080×700 最小值撑出屏幕。
