# Relay系统桌面体验检查（2026-11-06）

任务范围：启动、终端依赖、窗口与托盘、退出与资源清理、设置保存、菜单、聊天输入与页面切换。
用户原有任务、消息和未提交文件不作为验收数据修改；测试文件与缓存使用 D 盘独立目录。

## 已定位问题

| Before | After | Why |
| --- | --- | --- |
| 登录启动仍指向 PowerShell，手动启动记录携带 `--no-window` | 原生 GUI 为入口，登录才追加静默参数 | 消除终端依赖，点击图标就显示窗口 |
| 创建窗口前等待桥接启动 | 先显示窗口，再启动桥接和客户端 | 慢连接不再表现为图标无响应 |
| 消息增多时整页变高，输入框在窗口外 | 待修复 | 输入区必须保持可见 |
| 设置页保存失败只记日志，且内存已被改动 | 待修复 | 不能虚报成功 |
| 连接器更改未计入重启提示 | 待修复 | 界面应反映实际生效时机 |
| 退出事件中不等待异步资源释放 | 待修复 | 关闭程序不能留下桥接和未完成写入 |
| 桌面菜单点击无可见反应 | 待定位并修复 | 设置和退出入口必须可靠 |
| 安装目录网页落后于已提交源码 | 修复结束后同步并核验 | 用户必须实际用到已修复版本 |

## 启动修复验证

- 原生 GUI 的 PE subsystem 为 2；直接启动后 shell 命令已结束，窗口继续运行，窗口清单没有可见控制台。
- 保留 `--system-launcher` 集成配置，客户端启动由原生程序在窗口出现后以隐藏子进程触发。
- 登录命令参数及客户端启动有回归测试；不在命令中保存凭据。
- `trail` 已有其他活动任务；本记录独立保留，避免改动他人的 trajectory。
