## 限制

- MCP 使用独立 app-server，会话不等同于 ZCode 桌面已打开的聊天。需要续接时使用对应 MCP 返回的会话编号。
- 无头权限确认可能需要人工处理；程序不会自动升级执行权限。
- 当前版本的上游响应整轮结束后才包含会话编号，初始受理不会冒充已送达具体会话。
